# ATSAMG55J

A peripheral access crate for the ATSAMG55J chip from Microchip (née Atmel) for Rust Embedded projects.

## [Documentation](https://docs.rs/atsamg55j/)

This source was automatically generated using `svd2rust`, split into smaller pieces using `form` and formatted via `rustfmt`.

## Status

This crate is a local experiment to see whether the active `atsamd-rs` PAC generation
pipeline can be extended to cover `ATSAMG55J19`.
